# ポモドーロタイマー with ゲーミフィケーション

ゲーミフィケーション要素を組み込んだポモドーロタイマーアプリケーションです。経験値システム、達成バッジ、統計機能により、ユーザーのモチベーション維持と継続利用を促進します。

## 機能

### 🍅 ポモドーロタイマー機能
- 25分間の作業セッション
- 5分間の短い休憩
- 15分間の長い休憩（4回目の作業後）
- タイマーの一時停止・再開・停止機能
- セッションのスキップ機能

### 🎮 ゲーミフィケーション機能

#### 経験値システム
- ポモドーロ完了ごとに100 XP獲得
- 500 XPごとにレベルアップ
- 次のレベルまでの進捗表示

#### 達成バッジシステム
- **First Success**: 初回ポモドーロ完了
- **3 Days Streak**: 3日連続完了
- **Weekly Master**: 今週10回完了
- **Level 5**: レベル5到達
- **Level 10**: レベル10到達
- **Streak Master**: 7日連続完了

#### 統計・分析機能
- 連続日数の追跡（ストリーク）
- 週間統計とグラフ表示
- 月間統計と完了率
- 日別完了数の可視化

## 使用方法

### メインアプリケーションの起動
```bash
python main.py
```

### デモンストレーション（短時間版）
```bash
python demo.py
```

### 利用可能なコマンド
- `start` - ポモドーロを開始
- `pause` - タイマーを一時停止
- `resume` - タイマーを再開
- `stop` - タイマーを停止
- `skip` - 現在のセッションをスキップ
- `status` - 現在の状態を表示
- `stats` - 統計とバッジを表示
- `weekly` - 週間統計を表示
- `monthly` - 月間統計を表示
- `help` - ヘルプを表示
- `quit` - アプリケーションを終了

## ファイル構成

- `main.py` - メインのポモドーロタイマーアプリケーション
- `point.py` - ゲーミフィケーションシステム（XP、バッジ、統計）
- `demo.py` - デモンストレーション用スクリプト
- `deliverManager.py` - 既存のレシピ配達ゲームシステム
- `pomodoro_data.json` - 進捗データの保存ファイル（自動生成）

## データの永続化

すべての進捗データ（XP、レベル、バッジ、統計）は`pomodoro_data.json`ファイルに自動保存されます。アプリケーションを再起動しても、これまでの進捗が保持されます。

## 技術的特徴

### アーキテクチャ
- イベント駆動システム（既存のEvent系クラスを活用）
- Singleton パターン（ゲーム状態管理）
- スレッドベースのタイマー実装
- JSON による永続化

### ゲーミフィケーション設計
- 即座のフィードバック（XP獲得通知）
- 段階的な報酬システム（バッジ）
- 進捗の可視化（統計グラフ）
- ストリーク機能による継続促進

## 開発・テスト

### 環境要件
- Python 3.7以上
- 標準ライブラリのみ使用（追加の依存関係なし）

### テスト実行
```bash
# コンパイルチェック
python -m py_compile main.py point.py

# デモ実行（短時間版）
python demo.py

# 対話式テスト
python main.py
```
