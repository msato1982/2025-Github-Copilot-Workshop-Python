## ポモドーロタイマー - カスタマイズ機能

このリポジトリには、カスタマイズ可能なポモドーロタイマーが含まれています。個人の好みに合わせた設定で、集中力と生産性を向上させることができます。

### 🍅 主な機能

#### ⏰ 柔軟な時間設定
- **作業時間**: 15/25/35/45分から選択可能（従来の25分固定から脱却）
- **休憩時間**: 5/10/15分から選択可能
- 個人のワークスタイルに合わせて最適な時間配分を設定

#### 🎨 テーマ切り替え
- **ライトモード**: 明るく活動的な雰囲気
- **ダークモード**: 目に優しい暗いテーマ
- **フォーカスモード**: 気が散らないミニマルなデザイン

#### 🔊 サウンド設定
- **開始音**: タイマー開始時の通知音のON/OFF
- **終了音**: タイマー終了時の通知音のON/OFF
- **ティック音**: 秒針音のON/OFF

#### 💾 設定の永続化
- すべてのカスタマイズ設定は自動的に保存されます
- 次回起動時に前回の設定が復元されます

### 🚀 使用方法

#### アプリケーション起動
```bash
python3 main.py
```

#### 機能テスト実行
```bash
python3 test_pomodoro.py
```

#### デモンストレーション
```bash
python3 demo_pomodoro.py
```

### 📋 メニュー構成

1. **作業セッション開始** - 設定した時間で集中作業を開始
2. **休憩セッション開始** - 設定した時間で休憩を開始
3. **一時停止/再開** - 進行中のタイマーを一時停止/再開
4. **停止** - タイマーを完全に停止
5. **設定** - 時間、テーマ、サウンドの設定変更
6. **統計** - 完了したポモドーロ数と現在の設定表示

### 🎯 ユーザーシナリオ例

#### プログラマー向け
```
作業時間: 35分 | 休憩時間: 10分
テーマ: Dark | サウンド: 開始音・終了音ON
```
深い集中が必要なコーディング作業に最適

#### 学生向け
```
作業時間: 25分 | 休憩時間: 5分
テーマ: Light | サウンド: 開始音・終了音ON
```
習慣化しやすいクラシックな設定

#### ライター向け
```
作業時間: 45分 | 休憩時間: 15分
テーマ: Focus | サウンド: 終了音のみON
```
創作フローを維持する長時間集中設定

#### 在宅ワーカー向け
```
作業時間: 15分 | 休憩時間: 5分
テーマ: Light | サウンド: 全てON
```
短時間で区切る効率的タスク処理設定

### 📊 測定可能な効果

この実装により以下の測定が可能です：

- **ユーザー継続率**: カスタマイズ機能の有無による使用継続率の比較
- **設定選好**: 最も人気のある時間設定・テーマ・サウンド組み合わせ
- **完了率**: 設定別のポモドーロ完了率

- **言語**: Python 3
- **アーキテクチャ**: オブジェクト指向設計
- **データ永続化**: JSON設定ファイル
- **マルチスレッド**: タイマー処理の非同期実行
- **設定管理**: Enum型による型安全な設定
- **テスト**: 包括的なユニットテストと機能デモ
