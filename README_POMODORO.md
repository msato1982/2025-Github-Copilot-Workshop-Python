# ポモドーロタイマー - 視覚的フィードバック強化版

このプロジェクトは、視覚的フィードバックを強化したポモドーロタイマーの実装です。

## 実装された機能

### 🎨 視覚的フィードバック

#### 1. 円形プログレスバーのアニメーション
- 残り時間に応じて滑らかに減少するアニメーション表示
- Unicode文字を使用した美しい円形進捗表示
- リアルタイム更新（100ms間隔）

#### 2. 色の変化（グラデーション）
- 時間経過に応じた色の変化: **青 → 黄 → 赤**
- 進捗0-33%: 青色（集中開始時の冷静な色）
- 進捗34-66%: 黄色（中間の注意色）  
- 進捗67-100%: 赤色（終了近づく緊急色）

#### 3. 背景エフェクト
- **パーティクルエフェクト**: 集中時間中に背景に様々な記号（*、·、•、○、●、◦、◯、✦、✧、✩、✪、✫、✯、✰）がランダムに表示
- **波紋アニメーション**: 集中時間中に画面上に波紋が広がるアニメーション効果
- 没入感を高める視覚的演出

### ⏰ ポモドーロタイマー機能

#### 基本機能
- **集中セッション**: 25分間の集中時間（カスタマイズ可能）
- **短い休憩**: 5分間の短い休憩（カスタマイズ可能）
- **長い休憩**: 15分間の長い休憩（カスタマイズ可能）
- **サイクル管理**: 4セッション後に自動的に長い休憩

#### 操作機能
- **一時停止・再開**: セッション中の一時停止と再開
- **手動停止**: いつでもタイマーを停止可能
- **カスタム設定**: 各時間を自由に設定可能

#### プログレス表示
- リアルタイムの残り時間表示
- 進捗パーセンテージ
- 水平プログレスバー
- セッション数カウント

## 使用方法

### 1. 基本実行
```bash
python3 main.py
```

メニューから選択:
- `1`: ポモドーロタイマーを開始
- `2`: 機能テストを実行  
- `0`: 終了

### 2. 直接実行
```bash
# ポモドーロタイマー直接起動
python3 pomodoro_timer.py

# 機能テスト実行
python3 test_pomodoro.py

# デモ版実行
python3 pomodoro_demo.py
```

### 3. タイマー操作
タイマー実行中の操作:
- **P**: 一時停止/再開
- **S**: 停止  
- **Q**: 終了
- **Ctrl+C**: 強制終了

## カスタマイズ

初回実行時に設定をカスタマイズ可能:
- 集中時間（デフォルト: 25分）
- 短い休憩（デフォルト: 5分）  
- 長い休憩（デフォルト: 15分）
- 長い休憩までのセッション数（デフォルト: 4）

## 技術仕様

### 要件
- Python 3.6以上
- 標準ライブラリのみ使用（外部依存なし）
- ANSI色対応ターミナル

### 実装詳細
- **マルチスレッド**: タイマーロジックと表示更新を分離
- **ANSI エスケープシーケンス**: 色とカーソル制御
- **Unicode文字**: 美しい進捗表示
- **イベント駆動**: コールバック機能でセッション完了を通知

### アーキテクチャ
```
PomodoroTimer (メインクラス)
├── VisualEffects (視覚効果管理)
├── PomodoroConfig (設定管理)
├── PomodoroState (状態管理)
└── Threading (非同期処理)
```

## テスト目的

この実装は以下の目的で視覚的フィードバックを強化しています:

> **視覚的な没入感がユーザーの集中力に与える影響を測定する**

### 測定可能な要素
1. **色の変化による心理的効果**: 青→黄→赤の変化が集中維持に与える影響
2. **円形プログレスによる時間認識**: 直感的な時間把握の向上
3. **背景エフェクトによる没入感**: パーティクルと波紋による集中状態の維持
